## 2. 分层职责

| 层 | 职责 | 项目位置 |
| --- | --- | --- |
| Web 前端 | 检索、详情、认证、互动与管理页面；不保存数据库凭据 | `frontend/`（建设中） |
| 拦截器 | 端点级权限：未登录 401、非管理员 403，短路响应 | `config/AuthInterceptor.java` |
| Controller | HTTP 路由、参数绑定（@RequestParam/@PathVariable/@RequestBody）、统一响应 | `controller/` |
| Service | 业务规则：分页归一、存在性检查（仅已发布诗歌可互动）、属主校验、防重复预检、密码哈希 | `service/` |
| Mapper | 数据访问接口（无手写实现类，由 MyBatis 动态代理） | `mapper/` |
| Mapper XML | 全部 SQL 的唯一出处（课程"原生 SQL"要求的落点） | `resources/mapper/*.xml` |
| 全局异常 | 业务异常(400/403/404)与未知异常(500)转统一 JSON，完整堆栈进日志 | `common/GlobalExceptionHandler.java` |

## 5. 关键实现机制（答辩讲解要点）

1. **BCrypt + Session 认证**：注册时 `passwordEncoder.encode(明文)`（自动随机盐）入库，登录时 `matches(明文, 库中哈希)`；成功后身份写入 HttpSession，浏览器凭 JSESSIONID（HttpOnly）找回会话。用户不存在与密码错误返回同一句提示，防用户名枚举；账户停用（`account_status='disabled'`）拒绝登录。
2. **声明式权限**：`@RequireLogin` / `@RequireAdmin`（支持方法级与类级）+ `AuthInterceptor.preHandle` 短路——未进入 Controller 就返回 401/403 JSON。
3. **资源级权限**：Service 校验资源属主（如评论改删），非属主 403，管理员删除放行；userId 一律取自会话，绝不接受前端传入。
4. **动态 SQL**：`<if>/<where>/<choose>/<include>` 拼组合检索条件，参数全部 `#{}` 预编译占位符（防注入）；检索、详情、互动统一附加 `publication_status='published'`。
5. **覆盖式写入（upsert）**：评分用 `ON DUPLICATE KEY UPDATE`，以受影响行数（1=新增/2=更新）区分 created/updated，消除"先查后插"的并发竞态。
6. **发布状态与保留历史**：下架 = `publication_status` 变更为 withdrawn；评分/评论/收藏外键为 RESTRICT，互动历史不随下架或账号停用丢失；物理删除仅适用于无关联记录的数据。
7. **派生值不落表**：字数 `CHAR_LENGTH(content)`、平均分、评论/收藏数均在视图或查询中计算；JSON 字段（createYear/form/wordCount 等）由 SQL 别名保持一致，前端不受表名调整影响。
8. **分层防御**：应用校验 → Service 预检 → 数据库约束（CHECK/UNIQUE/外键/ENUM）与触发器（SIGNAL/时间校验）→ 事务存储过程回滚；前端拿到的都是友好提示。
