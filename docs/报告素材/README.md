## 图和运行记录

- Mermaid 数据流图、架构图可在支持 Mermaid 的工具中渲染；E-R 图可用 diagrams.net 或 draw.io 打开。
- 修改实体属性后先运行 `../er/gen_er_drawio.py` 更新 draw.io 源图，再运行 `../er/render_er_preview.py` 更新快速预览。
- SQL 运行结果必须来自目标 MySQL 环境。报告应注明数据库版本、执行时间、输出结果和截图；当前素材未声称已经运行或通过测试。
- 数据库初始化顺序及脚本用途见 `../../README.md`。`01_poetry_schema_mysql.sql` 与建库、建表、索引三个分步脚本是两种等价的结构初始化方式。

## 数据库设计要点

- 10 个关系模式：8 个核心实体和 2 个多对多联系表。
- 诗歌字数以 `CHAR_LENGTH(content)` 派生；`poem_comment.like_count` 是统计值，不建逐用户点赞实体。
- 诗歌下架用状态字段；物理删除遵循外键限制，保留互动记录。
- MySQL 8.0.16+、InnoDB、`utf8mb4_0900_ai_ci`，诗歌标题和正文分别使用 ngram FULLTEXT 索引。
