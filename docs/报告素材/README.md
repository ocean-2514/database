## 使用说明

1. **图**：数据流图与架构图在本素材中是 Mermaid 源码（可在 [mermaid.live](https://mermaid.live) 渲染预览），正式报告建议在 draw.io 中按同样结构重绘导出 PNG；E-R 图已有 drawio 源文件，直接导出。
2. **运行结果**：`04-SQL与运行结果.md` 中的 JSON 均为本项目真实接口响应（非编造），报告中可粘贴 JSON 或用浏览器/Apifox 截图。
3. **数据部分**：按规划后续系统建设诗歌库后再补"数据获取与清洗"一节；`sql/08_expand_data.sql` 不进入报告正文，可在"总结与展望"提及。
4. **更新责任**：前端章节由石朋松在联调后补充；每人总结自写；素材有出入时以代码和 `sql/` 脚本为准。

## 项目关键数字（写总结/摘要时用）

- 数据库：10 张表（8 实体 + 2 个 m:n 联系）、3 个视图、5 个触发器、4 个存储过程（含事务）、5 个流派、ngram 中文全文索引
- 后端：Spring Boot 3 + MyBatis（全手写原生 SQL），**32 个 REST 接口**（检索 4、认证 4、收藏 3、评分 3、评论 4、管理 14）
- 测试：约 60 个端到端测试场景全部通过（含角色校验、触发器拦截、事务回滚、平均分联动等）
- 密码安全：BCrypt 哈希存储；配置外置（密码不进 git）
