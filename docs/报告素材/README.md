## 数据库设计要点

- 10 个关系模式：8 个核心实体和 2 个多对多联系表。
- 诗歌字数以 `CHAR_LENGTH(content)` 派生；`poem_comment.like_count` 是统计值，不建逐用户点赞实体。
- 诗歌下架用状态字段；物理删除遵循外键限制，保留互动记录。
- MySQL 8.0.16+、InnoDB、`utf8mb4_0900_ai_ci`，诗歌标题和正文分别使用 ngram FULLTEXT 索引。

## 服务端实现要点

- Django 只用做路由、请求处理、签名 Cookie 会话和数据库连接；数据定义在 `../../sql/`，数据操作在 `../../backend_django/api/repositories/`。
- 没有 Django model、QuerySet、`filter()` 或 migrations；`sql/04`—`sql/06` 的视图、触发器、存储过程均被实际调用。
- 数据库配置通过 `backend_django/.env` 或环境变量提供，不写入仓库。
