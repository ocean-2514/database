## 三、作业内容说明

## 1. 系统背景与目标

本系统以诗歌信息管理为应用背景，设计并实现一个中等规模的数据库应用系统。系统面向普通用户提供诗歌检索、赏析、评分、评论和收藏功能，面向管理员提供诗人、诗集、诗歌、流派等基础数据的维护功能。通过本系统，用户可按标题、诗人、流派、年代、诗集等多种条件组合检索诗歌，并查看诗歌详情、进行互动；管理员可对诗歌相关数据进行增删改查管理。

## 2. 系统包含的实体（8个）

| 序号 | 实体名称 | 主要属性                                                 | 说明                   |
| ---- | -------- | -------------------------------------------------------- | ---------------------- |
| 1    | 诗人     | poet_id、姓名、笔名、性别、生年、卒年、国籍、简介        | 诗歌创作者             |
| 2    | 诗集     | collection_id、诗集名称、出版年份、出版社、ISBN、简介    | 诗歌合集               |
| 3    | 诗歌     | poem_id、标题、正文、创作年份、体裁、字数、赏析、poet_id | 核心实体               |
| 4    | 流派     | genre_id、流派名称、描述                                 | 如新月派、现代派、朦胧诗派等 |
| 5    | 用户     | user_id、用户名、密码、邮箱、角色、注册时间、账户状态    | 系统使用者             |
| 6    | 评分记录 | rating_id、user_id、poem_id、评分、评分时间              | 用户对诗歌的评分       |
| 7    | 评论     | comment_id、user_id、poem_id、评论内容、评论时间、点赞数 | 用户对诗歌的评论       |
| 8    | 收藏记录 | favorite_id、user_id、poem_id、收藏时间、收藏类型        | 用户收藏诗歌           |

## 4. 系统主要功能

## 检索功能：

* 按诗歌标题模糊搜索

* 按诗人姓名搜索

* 按流派筛选

* 按创作年份、体裁筛选

* 按诗集名称搜索

* 按诗歌正文全文检索

* 组合条件检索（流派+年代+诗人）

* 查看诗歌详情（含诗人、流派、所属诗集、平均分、评论）

## 插入功能：

* 用户注册

* 管理员添加诗人、诗集、诗歌、流派

* 用户评分、评论、收藏

## 删除功能：

* 删除评论

* 取消收藏

* 管理员下架诗歌

## 修改功能：

* 修改用户信息

* 修改诗歌信息

* 修改评分、评论
